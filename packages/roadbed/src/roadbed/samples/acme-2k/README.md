# acme-2k (SYNTHETIC)

Event stream of a synthetic insurer tenant, 2,000 claims. The sample for the quickstart and the test fixture for `roadbed.labels` and `roadbed.evals`.

Generated by a synthetic insurer generator (seed 7). Every row is synthetic.

`slices.yaml` and `output.schema.json` are copied from the same run (`evals/`).

Every row is synthetic (`synthetic: true` on interactions, `syn-` id prefix on verdicts and outcomes). Inputs are
pseudonymised (`<PERSON_1>`, `<EMAIL_1>`, ...); a scan for email- and phone-shaped strings finds none.

| File | Rows |
|---|---|
| interactions | 2000 |
| verdicts | 2000 (approve 1738, fix 236, escalate 26) |
| outcomes | 1187 |

`stand_in_predictions.py` writes stand-in prediction files from a sealed holdout. No model runs.
