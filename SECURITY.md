# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Report a vulnerability

Report it in private. Do not open a public issue. Use one of these ways:

- Send an email to security@roadbed.ai.
- Use GitHub private vulnerability reporting on this repository.

We acknowledge each report within 72 hours. Please give us the steps to reproduce the problem and the version that you used.

There is no bug bounty.

## Scope

These parts are in scope:

- the engine
- the command line tool
- the SDK
- the JSON Schemas of the format

The website is not in scope.
